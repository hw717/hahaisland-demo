### 2. 用了什么方法

#### （1）建筑高度「三层精准赋高」（[`scripts/enrich-building-heights.mjs`](scripts/enrich-building-heights.mjs)）
按优先级由高到低为每栋建筑赋予物理高度 `h` 与层数 `levels`：
1. **第一层（OSM 实测标签回填）**：直接解析 OSM `height` 标签（93 栋）或 `building:levels` 标签（329 栋；非居住建筑按 $3.5\text{ m/层}$、居住/宿舍类按 $3.0\text{ m/层}$ 折算）。
2. **第二层（南北全域具名建筑规则字典）**：覆盖清华、北大、五道口及南半区中关村、人大、北理工地标写字楼与教学公寓的正则规则，共精确命中 **733 栋**（如科技大厦 A/B/C 座 88 m、中关村科贸电子城 80 m、数码大厦 75 m、海龙大厦 65 m、北理工中心教学楼 56 m、人大明德主楼 42 m 等）。
3. **第三层（几何面积分级兜底）**：对其余 2,925 栋无名建筑按 WGS84 基底面积 $A$ 分四档赋高（$<120\text{ m}^2 \to 4.5\text{ m}$、$<350\text{ m}^2 \to 9\text{ m}$、$<1200\text{ m}^2 \to 16\text{ m}$、$\ge 1200\text{ m}^2 \to 21\text{ m}$）。全库建筑高度分位数：$P_{10}=9\text{ m},\ P_{50}=16\text{ m},\ P_{90}=21\text{ m},\ \max=88\text{ m}$。

#### （2）点位与路段的静态光学底座预烘焙（[`scripts/build-solar-features.mjs`](scripts/build-solar-features.mjs)）
1. **8 方位建筑遮挡仰角 `horizon[8]`**：在局部米制平面将 4,080 栋建筑轮廓按 $\le 3\text{ m}$ 步长密化为 **223,293 个立面采样点**；检索目标点 $150\text{ m}$ 半径内所有外墙计算遮挡仰角 $\arctan((h - 1.5)/d)$，每个 $45^\circ$ 主扇区内部再划分为 9 个 $5^\circ$ 子分位取最大值后再平均，防止单栋细高塔楼误遮整个 $45^\circ$ 象限。长路段（$\ge 60\text{ m}$）取 $1/6,\ 1/2,\ 5/6$ 三分点平均值。
2. **天空开敞度 `svf`、林荫 `canopy` 与夜间照明 `lamp`**：在 $100\text{ m}$ 半径内反距离加权街景语义分割分位数（全图覆盖率 **89.7%**）；公园内无街景处取同类公园中位数并受建筑天际线 $\cos^2(\overline{\text{horizon}})$ 约束；公园多边形内部赋予 `+0.15` 林荫加成。

#### （3）毫秒级太阳几何、光感评分与高权重寻路（[`route-demo/core.mjs`](route-demo/core.mjs)、[`route-demo/places.mjs`](route-demo/places.mjs)）
1. **太阳位置与物理照度**：`computeSunPosition()` 基于 Cooper 赤纬方程与均时差计算北京地方太阳高度角 $\alpha$ 与方位角 $\theta$（默认秋冬季路演切片 `dayOfYear = 319`）；`evaluateSolar()` 对 `horizon[8]` 做方位角线性插值后通过 Sigmoid 过渡计算向阳率 `litRatio`，合成白天直射+漫射照度 `light`（0–100）；日落后自动切换基于 `lamp` 与 `svf` 的夜间柔光评分。
2. **双模式疗愈评分与 40% 高权重融合**：支持 **`warm`（追光 40%）** 与 **`shade`（林荫 40%）** 两种模式（黄金时刻 $\alpha \le 20^\circ$ 无遮挡点位获 `1.18×` 暖光加成）；`blendSolar()` 将光照适应度映射至与静态匹配一致的 `30–70` 区间，默认以 **$\lambda = 0.40$** 权重参与最短路阻抗 `shortest()`、路径推荐 `recommend()` 与公园 POI 排序 `rankPlaces()`。

#### （4）前端 2.5D 建筑阴影与交互（[`dist/mobile.mjs`](dist/mobile.mjs)、[`route-demo/app.mjs`](route-demo/app.mjs)）
* `projectBuildingShadowRing()` 根据太阳高度角（$\tan\alpha$ 下限保护 `0.18`，最长阴影截断 `110 m`）与反太阳方位角计算顶点偏移，通过凸包拼接基底与屋顶投影，在 Leaflet Canvas 层中实现全域建筑阴影零卡顿实时重绘。
* 界面新增：`07:00 – 19:00` **日照时间轴滑块**、快捷时刻按钮（`08:30` / `12:30` / `15:00` / `16:30`）、**`▶ 流转`** 自动演示、街道图层中**「实时日照与阴影」**开关及**「纯光照热力 / 综合匹配」**切换、点位经纬度光照与遮挡仰角诊断卡片，以及**「清华园 · 五道口 · 中关村 · 人民大学」南北片区快捷起点**。

### 3. 达成了怎样的效果

* **全域无死角覆盖**：彻底解决原 `city-buildings.geojson` 仅覆盖成府路以北（2,252 栋）的局限，扩展至北起清华紫荆/圆明园、南至北三环中关村/人民大学的完整研究区（**4,553 栋**前端建筑轮廓、**1,933 栋**南半区建筑）。
* **时间维度「逐光换路」**：拖动日照滑块或点击 `▶ 流转` 时，全图建筑阴影实时扫过街区；同一组起终点在上午、正午与傍晚会因教学楼和写字楼阴影遮挡变化而自动重新规划路线，直观呈现“上午走东侧向阳、下午走西侧暖阳”的微气候差异，并展示整条路线的**暖阳占比与平均照度**。
* **轻量零卡顿 & 完整验证**：所有 31,406 个位置的遮挡与开敞特征已完成离线烘焙，前端交互仅做一次查表插值与三角函数运算；[`scripts/check-assets.mjs`](scripts/check-assets.mjs) 的 218 项静态引用及 `solar.test.mjs`、`routing.test.mjs`、`mobile-map-layers.test.mjs` 等 **64 项核心自动化测试全部通过**（`rooms.test.mjs` 的 10 项联机房间测试依赖本地 TCP 监听权限）。

## 二、本地运行方式

### 1. 环境准备
* 安装 **[Node.js 22 或以上版本](https://nodejs.org/)**（无需执行 `npm install`，项目零第三方 npm 运行依赖）。

### 2. 一键启动
* **Windows**：直接双击 [`启动本地Demo.bat`](启动本地Demo.bat)
* **macOS**：双击 [`启动本地Demo.command`](启动本地Demo.command)（若首次拦截，请参考 [`Mac启动说明.md`](Mac启动说明.md)）
* **命令行**：在 `kunshan-demo` 目录运行：
  ```sh
  npm start
  ```
启动后在浏览器打开 **http://127.0.0.1:4173/**（或直达地图页 **http://127.0.0.1:4173/#map**）。

### 3. 快速体验新功能
1. 进入地图页后，点击右上角偏好图标 → 点击时间/路线栏（如「30 分钟 · 回到起点」）→ 在**「南北片区快捷起点」**一键切换 **`清华园`**、**`五道口`**、**`中关村`** 或 **`人民大学`**。
2. 拖动地图上方的 **日照时间轴（07:00 – 19:00）** 或点击 **`▶ 流转`**，观察全域 2.5D 建筑阴影与推荐路线的变化；点击 **`追光 40%`** 按钮可切换至 **`林荫 40%`** 或关闭日照加权。
3. 点击左侧 **街道图层图标**，开启 **「道路匹配度」** 并点击 **「切换纯光照热力」**，可查看全图路网的实时光照评分热力分布；开启 **「街景照片」** 点开任意蓝点，可查看该经纬度的**实时光线值、当前方位建筑遮挡角、SVF 开敞度与最佳疗愈时段**。

## 三、后续如何进一步改进

1. **建筑物高度数据源精化（消除面积兜底误差）**
   * 目前仍有 2,925 栋未标注 `height` / `building:levels` 且未命中具名字典的无名建筑采用基底面积四档兜底（最高 21 m），在中关村或大型住宅区可能低估高层塔楼的阴影长度。后续建议融合开源建筑高度栅格（如 CNBH-10m）或基于街景视角反演建筑立面高度，进一步校准无名高层建筑。
2. **分节气与落叶物候多切片烘焙**
   * 当前 `computeSunPosition()` 已支持传入 `dayOfYear` 切换春分/夏至/秋分/冬至太阳高度角，但街景分割得到的 `canopy` 树冠遮蔽度尚未区分常绿与落叶树种的冬季/夏季透光率变化。后续可在 `build-solar-features.mjs` 中叠加校园树木点位或分季节透射曲线，并支持前端直接切换“四季/节气预设”。
3. **补充南半区探索任务点与实时街景样本**
   * 目前 52 个探索任务点（`tsinghua-points.json`）及 100 张本地历史街景照片主要集中在清华校园及周边。伴随建筑底图已扩展至中关村与人大片区，后续可扩充南半区的文化地标、城市口袋公园 POI 与近期街景采样，消除历史街景采集年份偏旧带来的环境偏差。
4. **微气候多因子耦合与个性化权重联动**
   * 在现有「光照 + 林荫 + 遮挡」基础上，可进一步引入风廊迎风面/背风面评估与地表辐射温差（如冬季避风向阳、夏季通风林荫），并将用户的心理学画像（Big Five / MBTI）或历史停留轨迹（Stay Point / 回游偏好）与日照权重 $\lambda$ 自动联动。
5. **移动端与小程序上线性能优化**
   * 当前全量 `graph.json`（约 6.12 MB）与 `city-buildings.geojson`（约 1.44 MB）在本地零延迟加载，但上线公网 Web 或微信小程序时建议开启服务器 Gzip/Brotli 压缩，并按空间网格（Tile/Quadkey）分片懒加载建筑轮廓，以显著缩短弱网下的首屏加载时间。
