# HahaIsland · 城市游乐场（昆山杯更新版 Demo）

本仓库为 **HahaIsland（斓图）** 昆山杯复赛迭代版 Demo 分享仓库，核心包含海淀南北全域建筑补全（清华、北大、五道口 + 中关村、知春路、人民大学）、2.5D 动态日照阴影模拟与 40% 光照高权重疗愈寻路功能。

* **完整可运行目录**：[kunshan-demo/](./kunshan-demo/)
* **更新说明与技术文档（数据、方法、效果、后续改进）**：请见 [kunshan-demo/README.md](./kunshan-demo/README.md)

## 快速运行

1. 点击页面右上角绿色 **<> Code → Download ZIP** 下载并解压（或 git clone https://github.com/hw717/hahaisland-demo.git）。
2. 安装 [Node.js 22+](https://nodejs.org/)（无需 
pm install）。
3. 进入 kunshan-demo/ 文件夹：
   * **Windows**：双击 启动本地Demo.bat
   * **macOS**：双击 启动本地Demo.command
   * **命令行**：运行 
pm start
4. 在浏览器打开 http://127.0.0.1:4173/（或直达地图页 http://127.0.0.1:4173/#map）。
